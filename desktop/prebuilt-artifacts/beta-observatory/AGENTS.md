# Agent Observatory

This is a maintained prebuilt React/TypeScript artifact for the Skillz beta runtime. Keep the catalog grounded in planner.py, live_test_loop.py, tree_loop.py and the context, discovery, evidence, and issue modules. Distinguish directly reported events from inferred phase participation; never invent runtime timestamps. The sample must remain explicitly illustrative.

Preserve the dynamic SKILLZ_ARTIFACT_READY protocol, Docker isolation, file/API gateways, and runtime gateway. Runtime credentials belong only in server environment variables. Runtime access is a desktop-owned capability; generated files cannot grant it. Playback must never call execution endpoints. Do not automatically approve planner decisions.

Keep the catalog, event mapping, playback, runtime connection, and presentation in separate modules. Run npm run build and npm test after changes; inspect the responsive UI. Recordings are owned and persisted by the desktop, outside this repository. Do not modify other artifacts or the parent library from an artifact-agent session.
